# Доска визуальных референсов (категория A — только изучать)

> **Обновление 13.11.2026.** Владелец решил полностью уйти от прежнего оформления. Упоминания «CMYK 2.0», бумажного фона, полутонов, меток реза и полароидов в этом документе — описание старого сайта, а не ориентир для нового. Концепции свободны в палитре и приёмах.

Правила (см. `COMPONENT_REUSE_POLICY.md`): изучаем композицию, типографику, иерархию, подачу товара, навигацию, анимации, сценарии. Не копируем сайт целиком, чужой фирменный стиль, тексты, фото, логотипы, иллюстрации, код.

Ориентиры владельца: креативные блоки, меньше квадратных элементов, без неона, спокойные тона, «премиум»; фирменная основа — CMYK 2.0 (бумага, голубой/пурпурный/жёлтый, полутона, метки реза, полароиды, пометки от руки).

## Статус (12.11.2026): пересобрано с просмотром галерей

**Чем смотрели.** Playwright (Chromium, ширина 1440) через прокси. Видели: превью-карточки на страницах тегов ecomm.design и крупные скриншоты главных страниц сайтов (страницы `/site/<название>/` в той же галерее, картинка целой главной страницы). Сами сайты-референсы не открывали (закрыты сетью). Скриншоты — в `scratchpad/refs/` сессии (в репозиторий не кладём).

**Важная оговорка.** Скриншоты в ecomm.design сделаны в разное время: у части они свежие (Marlene — 2025, Karst, Telegramme, Chani, Mishmash), у части старые (Sticker Mule, Pipsticks, Stickerbrand, Mapiful, Josh Ryan — по виду 2013–2019). Сайт сегодня может выглядеть иначе; мы оцениваем идею и композицию, а не актуальный вид. Видна только верхняя часть главной (около 1–2 экранов), без анимации, наведения и работы форм — про интерактив ничего не утверждаем.

## 4. Самые полезные для нас

1. Marlene Print House (№1) — тёплая бумага, три фото-плитки с подписью, блок с пунктирной «этикеткой»: ближе всего к «премиальной бумажной» теме без неона.
2. House of Blanks (№3) — метки по углам героя, плашки скидки за тираж, блок «как производим»: прямое родство с метками реза и «ступенями тиража».
3. Merchery (№2) — как показать B2B-мерч спокойно: логотипы, лента товаров «от» цены, набор подарков.
4. Newspaper Club (№4) — три формата тиража крупно с «от N шт» и кнопкой; понятный сценарий для печати «от 1 штуки».
5. Chani Shop (№11) — бумажные рваные края и «прищепки»: наши полароиды и канат, но чище.

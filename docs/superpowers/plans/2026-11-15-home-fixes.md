- Все ограничения раздела Global Constraints плана `docs/superpowers/plans/2026-11-15-home-page.md` действуют без изменений (цвета/шрифт из токенов, без новых библиотек и CDN, движение только на наведении, `prefers-reduced-motion`, шрифт ≥ 12 px, зона нажатия ≥ 44 px, нет горизонтальной прокрутки на 360 px, адрес «Челнокова, 9»).

- Скриншоты для оценки: 1920, 1440, 1024, 768, 360 px, viewport-кадры блока (не только full-page), смотреть каждый.
- Готово, когда `npm test`, `npm run build`, `npm run check:links` зелёные.

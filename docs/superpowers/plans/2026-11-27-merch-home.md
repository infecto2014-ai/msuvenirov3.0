# Новый концепт главной — план реализации

> Исполнители применяют выбранные навыки по AGENTS.md, без обязательного запуска всего набора.

**Цель:** показать новую главную из навигации и двух блоков по референсу владельца.
**Архитектура:** Astro, три изолированных компонента home-concept; существующая BaseLayout получает отдельный режим оформления только главной. PNG и шрифт лежат локально. Заявка использует существующий data-order.
**Стек:** Astro 5 + Preact, существующий npm, без новых JS-зависимостей.
**Описание:** ../specs/2026-11-27-merch-home-design.md

## Условия проверки

- Лицо мужчины скрыто, PNG независимы, картинки не становятся общим склеенным баннером.
- «МЕРЧ» читается и масштабируется на всех ширинах; кнопки и подписи не перекрыты.
- Только два раздела главной; другие страницы и настоящий логотип сохраняются.
- Фильтры не ломают композицию, работают ссылки, виден фокус; режим без JS сохраняет доступ к изделиям.
- Никакой отправки заявок и публикации на рабочем сервере.

## Review Focus

1. Картинки владельца придут другого размера/пропорций, чем заказано → блок не должен разъезжаться: у каждой картинки заданы `aspect-ratio` и `object-fit` (Task 2, тест `Pic`).
2. В смете лежат позиции со старого сайта/из другой вкладки (localStorage с чужой версией данных) → окно заявки открывается и не падает (Task 3, тест `estimate`).
3. JavaScript выключен или не загрузился → меню «Каталог», вопросы и лента работ остаются доступными (`<details>`, прокрутка ленты нативная) (Task 2, 5; проверка в Task 6).
4. Длинные названия/цены (например «от 1 100 ₽», «Брак по нашей вине переделаем бесплатно») на 360 px не вылезают из карточек (Task 6, скриншоты).
5. Ссылка ведёт на адрес без страницы → на тестовой копии 404 без стиля; каждая внутренняя ссылка обязана иметь файл в `dist/` (Task 2, `scripts/check-links.mjs`).

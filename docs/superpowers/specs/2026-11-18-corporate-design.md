# Компаниям — описание реализации

Задание владельца: «Блок для компаний продолжай в том же духе, агентов не забывай подрубать ux pro max и superpower». Продолжаем восстановление существующей страницы /korporativnym-klientam в стиле «О нас», а не переписываем главную. Владелец уже передал выбор оформления исполнителю и разрешил публикацию проверенной работы в main.

## Подход
Используем Astro + существующие Button/HeroArt/SectionHead/Contacts/Faq. Структура: первый экран с новым котом → подтверждённые логотипы → компактные раскрываемые направления → реальные кейсы → этапы → условия → FAQ → запрос КП/контакты. Самостоятельное решение исполнителя: текстовая секция 2.0 адаптируется компактно, без нового калькулятора или прайса. Альтернативы длинной посадочной и отдельного мини-приложения не соответствуют задаче продолжить существующий сайт и запросить КП.

## Ограничения
- Все бизнес-условия из .superpowers/corporate-v2-source.ts. Текущие контакты из site.ts; адрес Челнокова, 9. Цветовые минимумы сверять с pricing.ts.
- Подтверждённые логотипы client-1/2/4/5/6/7/8, не client-3. Реальные кейсы с существующими фотографиями, не portfolio-14. Изображение кота — иллюстрация, не кейс.
- Никаких выдуманных сроков, чисел, доставки, персонального менеджера из todo. Цен и калькулятора на странице нет по решению владельца из 2.0.
- Форма общая: data-order с запросом КП; тестовые заявки не отправлять. PDF не добавлять: существующего kp-msuvenirov.pdf в проекте нет.
- На экранах ≤900 px кот выше кнопок. Сохранить синий цвет, Onest, доступность, target=blank с rel=noopener. Раскрытие через native details, содержимое доступно без JS.

## Приёмка
Типы/сборка, npm test и check:links. В браузере 1440/1024/768/360 с JS и без JS: изображения, направления и условия, отсутствие переполнения, открытие КП с правильным комментарием, правильный адрес. Никаких отправок формы. Основная модель проверяет результат субагента; перед публикацией отдельный независимый обзор.

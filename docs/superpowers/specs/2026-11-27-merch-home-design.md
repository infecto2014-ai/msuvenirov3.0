# Новый концепт главной: первые два блока

Источник — приложенный владельцем концепт и прямое поручение от 27.11.2026 выполнить план, распределить работу, самостоятельно создать PNG и показать результат. Детали реализации ниже — выбор исполнителя в рамках поручения.

- Только новая навигация и первые два блока главной. Страницы услуг, цены, смета и логика заявки сохраняются. Прежние компоненты главной остаются в проекте для дальнейшей работы; в новом двухблочном показе они не выводятся.
- Белый фон #FAFAF9, чёрный #101010, лайм #C8FF00, спокойный серый #60605A. Настоящий логотип в чёрном цвете; новый логотип не генерировать.
- Типографика: локальный узкий Oswald с кириллицей для крупного наклонного «МЕРЧ»; существующий Onest для навигации и текста. Слово остаётся HTML-текстом, растягивается вместе с экраном и накладывается на фотографическую композицию.
- Первый экран: коротко стриженный мужчина в белой свободной футболке со спины, небольшой поворот корпуса, лицо скрыто; отдельный прозрачный PNG. Подзаголовок «Печать на одежде и сувенирах в Калининграде». Лаймовая кнопка «Обсудить заказ ↗» открывает существующую заявку.
- Второй блок «На чём печатаем»: свободная предметная композиция, не сетка карточек. Отдельные прозрачные PNG тёмного свитшота, белой кружки и светлого шоппера с минимальными морскими принтами. Не выдавать их за фотографии выполненных заказов.
- Фильтры «Все», «Одежда», «Кружки», «Шопперы» действительно переключают предметы, поддерживают клавиатуру; без JS все изделия и ссылки доступны. У каждого изделия своя ссылка в существующий раздел.
- Навигация в стиле концепта: настоящий логотип, «На чём печатаем», «Услуги и цены», «Обсудить заказ»; мобильное меню без обязательного JS. Никаких третьего блока, деталей работ и нижних CTA из образца.
- Проверки: npm test, build, check:links; браузер 1440/1024/768/360, JS и без JS, меню, фильтры, заявки без отправки, изображения, горизонтальная прокрутка и reduced-motion.

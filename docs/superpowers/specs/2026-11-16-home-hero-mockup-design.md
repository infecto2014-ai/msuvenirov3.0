## Что на макете (делаем так же)
- Над заголовком — плашка-таблетка со значком короны: «Своя мастерская в Калининграде». (Раньше владелец просил убрать корону и штрихи у кота — новый макет это отменяет.)
- Заголовок в три строки: «Печать на одежде / и сувенирах / в Калининграде»; под «Калининграде» — синий росчерк и маленькое сердечко. «От 1 штуки» уходит из заголовка в строку преимуществ. Шрифт — как на макете (Onest, жирнее), а не Helvetica: на макете не Helvetica; вернуть Helvetica — одна строка.
- Строка из трёх преимуществ со значками и тонкими разделителями: «Печать **от 1 штуки**» (синим), «Быстрое изготовление», «Качественные материалы» — тексты владельца с макета.
- Кнопки прежние: «Выбрать изделие →», «Создать свой дизайн».
- Под кнопками — адрес со значком метки: «Сельма, ТЦ «Экватор», 2 этаж».
- Справа — крупный кот с прессом и кружками на сиренево-голубом пятне, сверху — контурная корона и три штриха, под котом мягкая тень.
- Фон — светлый, с мягкими сиреневыми волнами по краям.
- Полоса цифр под первым экраном — без изменений.

## Телефон
Одна колонка: плашка → заголовок → преимущества (столбиком) → кнопки → адрес → кот на пятне.

## Готово
Тесты, сборка, ссылки; 1440 / 1024 / 768 / 360 и без JS — без горизонтальной прокрутки; кот не наезжает на текст.

## Правки владельца (16.11.2026, второй макет — телефон `docs/design-refs/home-hero-mobile-2026-11-16.webp`)

2. Телефон — как на макете (без плашки): заголовок → кот на пятне с короной и штрихами → три преимущества в ряд (значок сверху, текст по центру, тонкие разделители) → кнопки во всю ширину → адрес по центру → полоса цифр.
3. «Исправь на всех страницах, что мы делали, под этот стандарт»: первые экраны всех страниц одежды (`GarmentHero` — футболки, худи, шопперы, бейсболки, спецодежда, форма, сублимация, DTF) делаются так же, как главная: тот же блок кота (пятно, корона, штрихи, тень), та же сетка на компьютере, тот же порядок на телефоне (заголовок → кот → цена «от» → кнопки → адрес). Общий блок кота — один компонент для главной и страниц одежды. Картинки котов теперь вырезаны по коту (без пустых полей): `<страница>-hero.webp` и `<страница>-hero-mobile.webp` (размеры — в `docs/IMAGES.md`).

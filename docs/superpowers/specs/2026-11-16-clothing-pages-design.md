# Раздел «Одежда» 3.0: правки футболок, общий шаблон, худи — описание

Дата: 16.11.2026. Продолжение `2026-11-16-tshirt-page-design.md` (всё, что там не изменено ниже, в силе).

## Зачем
Владелец посмотрел страницу футболок, прислал правки, сказал «да, делаем страницы» и поручил: «делаем страницу с худи по аналогии… по аналогии все страницы категории одежда запускаем в работу». Чтобы восемь страниц не расходились, страница футболок превращается в общий шаблон страницы одежды; каждая страница — файл данных.

## Решения владельца (16.11.2026)
1. **Шапка:** значок «Смета» рядом с кнопкой «Заявка» убрать («и он, и кнопка заявки»). *(Исполнитель: число позиций сметы — маленький кружок на кнопке «Заявка»; смета открывается в окне заявки, как и сейчас.)*
2. **Калькулятор футболок:** выбор изделия — три плитки «Футболка унисекс», «Детская», «Своя футболка»; отдельный переключатель «наша / своя» убрать.
3. **Принтов до 5** на взрослой, детской и своей футболке; **на детской — размеры принта до А3** (было до А4, 2 места).
4. **Итог калькулятора** «очень яркий, выедает глаза» — переделать спокойнее. *(Исполнитель: белая карточка с тонкой рамкой и мягкой тенью; синие — только сумма и кнопка «Оформить заявку»; разбивка серым текстом.)*
5. **Таблица цен:** заголовок «Цена печати на футболках»; подзаголовок переписать. *(Исполнитель: «Цена указана за одну футболку вместе с печатью. Чем больше тираж, тем дешевле каждая футболка».)*
6. **Взрослая размерная сетка — верная:** пометку «Размеры ориентировочные…» убрать.
7. **Рейтинги площадок над отзывами — только на главной** (на страницах услуг полосы рейтингов нет).
8. **Худи:** цена **2 600 ₽ при любом количестве** + печать (было «от 2 000 ₽, уточняйте наличие»; `blankFrom` убирается — цена точная); **цвета только чёрный и белый** (без минимума 5 шт); принтов — до 4, как было; больше 50 шт — индивидуально (общее правило одежды).
9. Коты для страниц — владелец пришлёт позже; до этого — подписанные заглушки.

## Подход (решение исполнителя, владелец согласился с планом)
Общий шаблон страницы одежды вместо копий страницы футболок:
- компоненты `src/components/tshirt/*` переименовываются/обобщаются в `src/components/garment/*` (первый экран, готовые варианты, «Подробнее об изделии», таблица цен) и получают данные пропсами;
- данные каждой страницы — `src/data/garments/<slug>.ts` по одному типу `GarmentPage` (заголовки, продукты калькулятора и плитки, варианты, цвета, характеристики, размеры, уход, ключевые слова отзывов, теги работ, вопросы, картинки котов);
- страница футболок переводится на шаблон без видимых изменений (кроме правок выше).

Порядок страниц: (1) правки футболок + шаблон, (2) худи, (3) шопперы и бейсболки, (4) спецодежда и спортивная форма, (5) сублимационная печать, DTF и сублимация без нанесения, хаб «Печать на одежде». Для этапов 3–5 — отдельные короткие описания (контент каждой страницы со старого сайта), этот документ покрывает этапы 1–2.

## Плитки изделий в калькуляторе
Калькулятор получает список плиток: `{ id, label, product, preset?: Record<string,string> }`. «Своя футболка» = продукт `tshirt-unisex` с `blank: 'own'` (группа «наша / своя» в калькуляторе скрывается, когда плитки заданы). На странице футболок: унисекс · детская · своя. Плитка выбирает продукт и накладывает preset.

## Худи — страница
`/pechat-na-hudi` (сейчас заглушка). Тот же порядок блоков, что у футболок: первый экран («Печать на худи в Калининграде **от 1 штуки**») → калькулятор (только худи; цвет — белый/чёрный кружками) → готовые варианты (4 из `garments.ts` 2.0 дословно; фото — настоящие работы с худи из `portfolio.ts`, где нет — `public/img/showcase/hoodie.webp` как изображение изделия) → конструктор → «Подробнее о худи» → работы (тег `hudi`) → отзывы со словом «худи» (добор из общей подборки) → вопросы (`services.ts` `/pechat-na-hudi`) → открытая таблица цен «Цена печати на худи».
- Характеристики и размеры худи в 2.0 помечены `todo` (не подтверждены): показываются с видимой пометкой «Характеристики уточняйте у менеджера», вопрос владельцу задаётся в итоговом сообщении. Цвет — только белый и чёрный (серый меланж из 2.0 не показывать).
- Картинки: `hoodie-hero` 2400×1400 (кот в худи держит/показывает худи с принтом на спине; кот справа, левая половина пустая), `hoodie-hero-mobile` 1200×1200 прозрачный.

## Ограничения
Все Global Constraints планов главной и футболок; цены только из `pricing.ts` (тесты на 2 600 ₽, 5 принтов, детские А3, цвета худи); главная не меняется, кроме шапки (п. 1).

## Как понять, что готово
`npm test`, `npm run build`, `npm run check:links` зелёные; страницы футболок и худи на 1440/1024/768/360 без горизонтальной прокрутки; плитка «Своя футболка» считает только печать; 5-й принт добавляется; на детской есть А3; итог калькулятора спокойный; в шапке нет значка сметы, счётчик на «Заявке»; тестовая копия обновлена.

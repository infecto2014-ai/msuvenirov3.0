## MSPricing — как считать

```js
const P = MSPricing;
P.categories                      // 12 категорий: {id, name, page, products:[…]}
P.categoryFrom('textile')         // {price: 290, unit: 'шт'} — цена «от» категории
const p = P.findProduct('textile', 'tshirt-unisex');   // изделие: {id, name, short, qty:{min,max,default,individualAbove}, options:[…], fromPrice, table}
const sel = P.defaultSelection(p); // {options:{blank:'ours', color:'white', print1:'a4', print2:'none', print3:'none', print4:'none'}, dims:{}, qty:1}
const q = p.quote(sel);            // {unit, total, breakdown:[{label, amount, per}], next:{qty, unit}, notes:[…], error?}
P.rub(1550)                        // «1 550 ₽»
p.ladder?.(sel)                    // ступени цены за штуку: [{from, price}]
P.dtfPrint                         // форматы принта: a6…a3 {label, size:'10×15 см', tiers}
```

Правила, которые уже внутри `quote()` и которые прототип обязан показать, а не пересчитывать сам: ступени тиража 1–4 / 5–19 / 20–50; несколько принтов — самый дорогой по полной цене, следующий −30 %, остальные −50 %; «Своя футболка» — только печать; «Другой цвет» — от 10 шт; больше 50 шт — индивидуальный расчёт (`q.notes`, `p.qty.individualAbove`); `q.next` — «ещё N шт — и цена за штуку ниже».

**Ни одной цены руками.** Все «от N ₽», цены в строках каталога, в калькуляторе и в готовых вариантах берутся из `MSPricing` скриптом при загрузке страницы. Цена «от» изделия — `product.fromPrice`.

## Что должен содержать каждый прототип (одинаково у всех трёх — для честного сравнения)

Папка `concepts/concept-…/prototype/`:

1. `index.html` — главная: полный первый экран по своей концепции + фрагмент каталога в своей подаче (не меньше 8 изделий из разных категорий с ценой «от» из прайса) + ещё 1–2 самых характерных блока концепции + подвал с контактами.
2. `futbolki.html` — страница «Печать на футболках»: первый экран, **работающий калькулятор** футболки унисекс (наша / своя, цвет, формат основного принта А6–А3, добавление 2–4-го принта, количество 1–50 и «больше 50»), итог с разбивкой, подсказка о следующей ступени цены, кнопки «В смету» и «Заказать»; затем 2–3 характерных блока (готовые варианты или характеристики, работы из `portfolio.json` с тегом `futbolki`, вопросы).
3. Смета и форма заявки — рабочее окно: «В смету» добавляет позицию (хранить в памяти страницы или `sessionStorage`), «Заказать» открывает форму (имя, телефон, способ связи, выбор «есть макет / фото или набросок / макета нет», комментарий). Отправка — имитация: показать экран «Заявка принята» с номером-заглушкой и пометкой «это прототип, заявка никуда не отправлена».
4. Навигация: шапка с меню по утверждённой структуре (Услуги, Цены, Подарки, Компаниям, Работы, Статьи, О мастерской, Контакты) — раскрывается как задумано в концепции; ссылки на несуществующие страницы ведут на `#` (или помечены). Главная ↔ футболки связаны.
5. Телефон: на 390 px всё работает, звонок и заявка под пальцем, итог калькулятора виден во время настройки, нет горизонтальной прокрутки.

## Технические условия

- Только статические файлы: HTML, CSS, один-два файла обычного JavaScript. **Без сборки, без фреймворков, без npm-зависимостей в проекте, без CDN.** Прототип должен открываться двойным щелчком и с любого статического сервера.
- Пути — относительные (`../../shared/...`), чтобы работало из любой папки.
- Шрифты: скачать нужные файлы woff2 из пакетов `@fontsource…` реестра npm (`npm pack <пакет>` во временной папке сессии или архив с registry.npmjs.org), положить в `prototype/fonts/` только используемые начертания (кириллица + латиница), вместе с файлом лицензии OFL из пакета. Никаких Google Fonts по сети.
- Анимации — CSS или небольшой собственный скрипт; движков не подключать. Соблюдать `prefers-reduced-motion`. Без скриптов страница читается: текст, заголовки и структура есть в HTML (цены подставляются скриптом — в прототипе это допустимо; в `<noscript>` дать ссылку «цены — в прайсе»).
- Доступность: фокус виден, кнопки — `<button>`, поля с подписями, диалоги закрываются по Esc, зоны нажатия ≥ 44 px.
- Тексты: русский, без штампов (`docs/ANTI_AI_SLOP.md`), только подтверждённые факты (`CLAUDE.md`, «Решения владельца»): заказ от 1 шт; ежедневно 10:00–20:00; ТЦ «Экватор», 2 этаж; большинство изделий в одном экземпляре делаем за час (как возможность); простой макет бесплатно; наценки за срочность нет; 10 000+ заказов; принт выдерживает 50+ стирок; организациям — счёт без НДС, договор, акт / УПД. Нельзя: доставка, предоплата для частных лиц, жёсткий срок ответа, вышивка, гравировка, рейтинги вне блока отзывов. Контакты — из `docs/CONTENT_INVENTORY.md`, раздел 1.
- Внизу каждой страницы — тонкая пометка: «Прототип концепции A / B / C. Не для публикации».
- Ничего из старого оформления (см. `BRIEF_FOR_CONCEPTS.md`, условие 1).

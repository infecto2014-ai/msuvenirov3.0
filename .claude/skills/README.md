# Скилы проекта

Установлены 12.11.2026 по заданию владельца. Источники, версии, лицензии и что именно взято — `docs/RESOURCE_LICENSES.md`, раздел «Скилы». Кто и на каком этапе применяет — `docs/AGENT_ROUTING.md`.

| Папка | Назначение |
|---|---|
| `frontend-design` | создание интерфейса с ясным визуальным замыслом |
| `impeccable` | критика, аудит и доводка дизайна |
| `ui-ux-pro-max` | справочник UX-правил, палитр, шрифтовых пар (поиск скриптом) |
| `web-design-guidelines` | чек-лист качества интерфейса (доступность, формы, анимации) |
| `seo` | базовый чек-лист технического и внутреннего SEO |
| `ux-writing` | тексты интерфейса: кнопки, ошибки, подсказки |

Правила скилов не отменяют решения владельца, `docs/ANTI_AI_SLOP.md` и `docs/DESIGN_BRIEF.md`. При противоречии главнее документы проекта.

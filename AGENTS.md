## Экономия за счёт выбора модели

Самостоятельно выбирай модель по сложности задачи. Не спрашивай пользователя о выборе модели.

Основная модель отвечает за:

- планирование и архитектуру;
- сложные ошибки и неоднозначные требования;
- решения, требующие понимания нескольких частей проекта;
- проверку результатов субагентов.

Используй дешёвую модель `gpt-6-luna` через субагента для задач с чёткими условиями и легко проверяемым результатом:

- поиск по коду и сбор фактов;
- замена текстов, цен и других однотипных данных;
- повторяющиеся правки по готовому образцу;
- вёрстка по подробному описанию;
- написание тестов по уже определённой логике;
- массовая обработка файлов.

Правила делегирования:

1. Мелкие задачи на одну-две простые правки выполняй сам: запуск субагента может стоить дороже.
2. Передавай субагенту только необходимый контекст. При выборе модели указывай `fork_turns: "none"`.
3. В задании указывай цель, конкретные файлы, ограничения и способ проверки.
4. Напоминай субагенту, что он работает в общем проекте и не должен отменять чужие изменения.
5. Не поручай нескольким агентам одновременно изменять одни и те же файлы.
6. Проверяй результат субагента перед тем, как сообщить пользователю о завершении.
7. Если дешёвая модель не справилась, уточни задание или выполни сложную часть сам. Не запускай бесконечные повторные попытки.
8. Используй только модели, доступные в текущем инструменте. Если дешёвая модель недоступна, продолжай самостоятельно.

Цель — уменьшать общую стоимость выполнения задачи с учётом запуска субагентов, передачи контекста и проверки результата, сохраняя качество.
